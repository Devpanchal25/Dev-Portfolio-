## 🚀 Key Features

- **📱 Live Interactive Android Device Simulator:** An in-browser Android 14 frame simulator featuring an operational status bar, clock, navigation gestures, and functional demo applications (Weather forecast simulator, Employee Performance task tracker, and Justicia AI legal query engine).
- **⚡ High Performance & 60fps Animation:** Hardware-accelerated transitions powered by `motion`, smooth scroll behaviors, zero re-render GPU cursor tracking, and optimized layout trees.
- **🎨 Dark / Light Mode Palette:** Clean dark terminal atmosphere with customizable high-contrast light mode toggle.
- **💼 Interactive Resume & Credentials Viewer:** Built-in modal viewer for PDF/Document resume preview, key metrics, and verified credentials (IBM SkillsBuild AI Certification).
- **✉️ Direct Email Dispatch:** Direct contact section equipped with instant Gmail deep links, custom mailto builders, and form dispatch fallback.
- **📊 Modern Architecture & Skill Breakdown:** Category-filtered technical skills with interactive search, timeline roadmap, and comprehensive project deep-dives.

## ⚙️ Local Setup & Run Instructions

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Devpanchal25/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Build for production:**
   ```bash
   npm run build
   ```
